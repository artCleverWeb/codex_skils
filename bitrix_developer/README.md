# Bitrix Codex Kit

Переносимый комплект инструкций для Codex, работающего с коробочными «1С-Битрикс: Управление сайтом» и «Битрикс24» версии ядра 25.1150.200 и новее.

## Установка

1. Скопируйте `AGENTS.md`, `.agents` и `prompts` в корень Bitrix-проекта.
2. Дополните `AGENTS.md` командами запуска и проверки конкретного проекта.
3. В новой задаче используйте подходящий файл из `prompts/` или сформулируйте задачу свободно — Codex выберет подходящий skill по его описанию.

Проектные соглашения имеют приоритет над универсальными рекомендациями комплекта, кроме ограничений безопасности и запрета на изменение ядра.
