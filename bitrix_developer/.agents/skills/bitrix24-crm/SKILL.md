# CRM коробочного Bitrix24

1. Уточни сущность, categoryId, stage semantics, пользовательские поля и права.
2. Предпочитай актуальные service/container, factory и item API; старые `CCrm*` используй лишь при необходимости.
3. Не обходи permission checks и контекст пользователя без явного обоснования.
4. Учитывай automation, timeline, search index, duplicate control и побочные события сохранения.
5. Массовые операции делай пакетными, идемпотентными и возобновляемыми.
6. Для REST учитывай scope, лимиты, пагинацию и повторную доставку.
7. Проверяй API по установленной версии `crm`; не переноси допущения из облака в коробку.
