# Компоненты Bitrix

1. Штатный компонент сначала скопируй в `/local/components`; исходник ядра не меняй.
2. Сохраняй публичные параметры и структуру `$arResult`, если изменение контракта не согласовано.
3. Нормализуй параметры, проверяй права, отделяй получение данных от представления.
4. Используй `class.php`, `executeComponent()`, корректные `StartResultCache`, `AbortResultCache`, `SetResultCacheKeys` и tagged cache по необходимости.
5. Не размещай бизнес-логику в шаблоне; `result_modifier.php` используй только для подготовки представления.
6. Для AJAX применяй поддерживаемые контроллеры/Actions и обязательную защиту sessid.
7. Строки интерфейса вынеси в `lang/`; ресурсы подключай средствами Bitrix.
