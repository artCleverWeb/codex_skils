# Интернет-магазин

1. Определи версии `catalog`, `sale`, типы цен, сайты, валюты и модель SKU.
2. Используй D7 API модулей Catalog/Sale; legacy допускай только с объяснением.
3. Учитывай контекст сайта, валюту, округление, НДС, права и многосайтовость.
4. Изменяй корзину и заказ через их API и сохраняй в корректной последовательности; проверяй `Result` и ошибки.
5. Не имитируй внутреннюю математику скидок, оплат или доставок вручную.
6. Обработчики событий делай идемпотентными и защищай от рекурсии.
7. Любые операции с реальными заказами и БД требуют согласования.
