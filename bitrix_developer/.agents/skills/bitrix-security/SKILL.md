# Безопасность

1. Определи границы доверия, роли, активы и возможные пути ввода данных.
2. Проверяй авторизацию и права на сервере; скрытие UI не является контролем доступа.
3. Для изменяющих запросов проверяй метод и sessid/CSRF. Валидируй по allowlist и экранируй по контексту вывода.
4. Используй ORM/параметризованные запросы; не склеивай SQL из ввода.
5. Проверяй загрузки по размеру, типу, расширению и месту хранения; предотвращай path traversal.
6. Не раскрывай секреты, stack trace и персональные данные; маскируй журналы.
7. На ревью ранжируй находки по риску, показывай путь эксплуатации и минимальное исправление без выполнения атаки.
