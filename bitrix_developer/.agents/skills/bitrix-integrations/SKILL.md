# Внешние интеграции

1. Зафиксируй контракт, авторизацию, таймауты, лимиты, пагинацию и семантику ошибок.
2. Используй HTTP-клиент проекта/Bitrix, проверяй TLS; секреты не помещай в код или логи.
3. Разделяй транспорт, DTO/маппинг и бизнес-логику.
4. Валидируй входящие webhook, подпись, timestamp и защиту от повторов.
5. Исходящие операции делай идемпотентными; используй ограниченные retry и очередь.
6. Не считай HTTP 200 бизнес-успехом без проверки ответа.
7. Добавляй безопасную наблюдаемость с correlation id и маскированием данных.
