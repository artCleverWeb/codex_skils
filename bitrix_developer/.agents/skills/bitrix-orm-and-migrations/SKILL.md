# ORM и миграции

1. Сначала изучи существующие таблицы, ORM-классы и механизм миграций проекта.
2. Описывай точные типы, required/default, validators, references и индексы; не путай ORM-тип с физическим типом MySQL.
3. Не выбирай лишние поля; контролируй join, runtime expressions, лимиты и порядок.
4. Обрабатывай `Result` и ошибки записи; транзакции используй с корректным rollback.
5. Миграции делай повторяемыми, совместимыми с развёртыванием и по возможности обратимыми.
6. Генерация и запуск миграции, а также любое обращение к БД требуют предварительного согласования.
