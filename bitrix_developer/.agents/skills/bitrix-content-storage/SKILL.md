# Инфоблоки и Highload-блоки

1. Не зашивай числовые ID без необходимости; используй конфигурацию и стабильные коды.
2. Выбирай только нужные поля, применяй фильтры и пагинацию, избегай N+1.
3. Учитывай множественные свойства, SKU, права, workflow и многосайтовость.
4. Для Highload-блоков проверяй существование сущности и полей, кешируй compiled entity только корректно.
5. Валидируй enum, файлы и пользовательские поля; различай отсутствие значения и пустое значение.
6. Создание или изменение структуры выполняй через согласованный механизм проекта и только после разрешения.
