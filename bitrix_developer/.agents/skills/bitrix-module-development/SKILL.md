# Разработка модуля Bitrix

1. Определи соглашения проекта по vendor, module id, namespace и версиям; при отсутствии запроси их.
2. Размещай модуль в `/local/modules`; ядро не меняй.
3. Разделяй установку, доменную логику, инфраструктуру и административный UI без переусложнения.
4. Сделай установку и удаление повторяемыми и безопасными; удаление пользовательских данных не выполняй по умолчанию.
5. Регистрируй события, агентов, файлы и ORM-таблицы симметрично; обновления версионируй.
6. Пользовательские строки вынеси в `lang/`, настройки проверяй и типизируй.
7. До запуска установки, миграции или изменения БД запроси разрешение.
