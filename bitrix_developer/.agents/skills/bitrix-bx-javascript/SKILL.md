# JavaScript и BX API

1. Продолжай используемый проектом способ подключения; предпочитай поддерживаемый BX API.
2. Не создавай глобальные переменные; обеспечь повторную инициализацию без дублирования обработчиков.
3. Используй `BX.ready`, `BX.Event`, `BX.ajax`/actions и UI extensions в соответствии с установленной версией.
4. Передавай sessid для изменяющих запросов; не доверяй клиентской валидации.
5. Не вставляй непроверенный HTML; экранируй данные по контексту.
6. Освобождай подписки и ресурсы в динамическом интерфейсе; обрабатывай ошибки и состояния загрузки.
7. Браузерную проверку выполняй только по прямому запросу.
