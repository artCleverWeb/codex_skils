# Аудит безопасности

Проведи аудит **[область]** без изменения файлов. Проверь серверные права, CSRF, XSS, SQL, файлы, SSRF, REST/webhook, секреты и персональные данные. Для каждой находки укажи критичность, условие эксплуатации, доказательство, затронутый путь/строку и минимальную рекомендацию. Не выполняй разрушающие проверки.
