# Git Developer

Универсальный скилл Codex для безопасной работы с Git, GitHub и GitLab.

Скопируйте .agents/skills/git-workflow в корень проекта или каталог пользовательских скилов Codex. Доступен автоматически и как $git-workflow.

Все изменяющие операции требуют явного подтверждения непосредственно перед выполнением. Read-only анализ разрешён без подтверждения.
