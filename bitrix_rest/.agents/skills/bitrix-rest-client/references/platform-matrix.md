# Матрица платформ и источников

## Сначала определить платформу

| Сценарий | Что проверять |
|---|---|
| Облачный Bitrix24 | Тариф, выданные scope, доступные `methods`, REST или REST 3.0, лимиты портала |
| Коробочный Bitrix24 | Версии ядра и модулей, установленные методы, настройки REST/OAuth, отличия от облака |
| «1С-Битрикс: Управление сайтом» | Наличие и версия модуля `rest`, собственные методы проекта, доступный механизм авторизации |

Не считать эти платформы взаимозаменяемыми. В старых коробочных версиях может отсутствовать метод или отличаться контракт.

- Сравнение REST и REST 3.0: <https://apidocs.bitrix24.com/api-reference/rest-v3.html>
- Лимиты: <https://apidocs.bitrix24.com/limits.html>
- Ошибки: <https://apidocs.bitrix24.com/error-codes.html>
- Официальный репозиторий документации: <https://github.com/bitrix24/b24restdocs>

Для точного метода открывать его страницу в API Reference. Не использовать случайный пример из поиска как доказательство актуального контракта.
