# Контрольный список локального приложения

## Архитектура

- Выбран сценарий: webhook, статическое, серверное UI-приложение или фоновое приложение.
- Определены облако/коробка, число порталов, scopes, placements и события.
- Внешний PHP-сервис не зависит от D7 без объективной необходимости.
- Tenant определяется по сохранённой установке, а не по произвольному URL клиента.

## Установка

- Endpoint использует HTTPS и проверяет вход установки.
- Установка повторяема и не дублирует bindings.
- Подтверждение завершения выполняется только после обязательной настройки.
- Ошибка оставляет установку в диагностируемом и безопасном состоянии.

## Токены

- `client_secret`, access/refresh tokens не попадают в Git и журналы.
- Токены шифруются и разделяются по порталам.
- Refresh защищён блокировкой или compare-and-swap.
- Отзыв доступа переводит установку в явное состояние, а не запускает бесконечный retry.

## Events и placements

- Обработчик события дедуплицирует доставку и быстро отвечает.
- Bindings регистрируются и удаляются симметрично.
- Сервер повторно проверяет права для действий из UI.
- HTML, URL перехода и параметры placement экранируются по контексту.
