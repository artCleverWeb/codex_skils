# Bitrix REST Codex Kit

Набор скилов для REST-интеграций Bitrix и Bitrix24 и локальных приложений на PHP 8.2+.

## Состав

- `bitrix-rest-client` — REST/OAuth/webhook-клиенты, batch, события, лимиты и синхронизация.
- `bitrix-rest-extension` — собственные REST-методы в коробочном Bitrix24 и «1С-Битрикс».
- `bitrix24-local-apps` — жизненный цикл локальных приложений, tokens, events и placements.

## Подключение

Скопируйте `.agents` в корень целевого проекта. Проектные инструкции и фактическая версия установленного Bitrix имеют приоритет над общими рекомендациями набора.
