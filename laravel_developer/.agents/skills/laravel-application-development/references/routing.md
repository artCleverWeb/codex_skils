# Маршрутизация по скилам

- HTTP JSON API и Resources: `$laravel-api-development`.
- Eloquent, SQL, schema и migrations: `$laravel-eloquent-database`.
- Authentication, policies, Sanctum/Passport и security: `$laravel-security-auth`.
- Jobs, queues, events, scheduler, Horizon, broadcasting/Reverb: `$laravel-queues-events`.
- PHPUnit/Pest, Pint, Larastan и CI: `$laravel-testing-quality`.
- Профилирование, кеш, Octane и оптимизация: `$laravel-performance`.
- Blade и Livewire: `$laravel-blade-livewire`.
- Inertia с Vue/React: `$laravel-inertia-frontend`.
- OpenAPI 3.1 и Dedoc Scramble: `$laravel-openapi-scramble`.

Официальные документы: <https://laravel.com/docs/12.x> и <https://laravel.com/docs/13.x>.
