# Разработка приложений Laravel

1. Определить Laravel/PHP по `composer.json`, структуру проекта, локальные инструкции и доступные проверки. Laravel 12 поддерживает PHP 8.2+, Laravel 13 требует PHP 8.3+.
2. Найти похожую реализацию и продолжить соглашения проекта. Не вводить repository/service/action/DTO слои без практической необходимости.
3. Использовать возможности Laravel и установленные пакеты прежде собственной инфраструктуры.
4. Держать контроллеры и команды тонкими; бизнес-правила размещать в согласованном проектом слое и отделять от транспорта.
5. Использовать container bindings только для реальной подменяемости; избегать facade/service-locator внутри доменной логики.
6. Получать конфигурацию через `config()`, не вызывать `env()` вне config-файлов. Не коммитить секреты.
7. Сохранять публичные маршруты, события, jobs, команды и контракты либо явно согласовать несовместимое изменение.
8. Добавить или обновить тесты на изменённое поведение и запустить доступные проверки.

Для выбора специализированного workflow прочитать [references/routing.md](references/routing.md).
