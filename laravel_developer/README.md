# Laravel Codex Kit

Переносимый набор скилов для Laravel 12–13. Laravel 12 поддерживается на PHP 8.2+, Laravel 13 — на PHP 8.3+.

Набор охватывает архитектуру, HTTP API, Eloquent и БД, auth/security, queues/events/Horizon/Reverb, тестирование, производительность/Octane, Blade/Livewire, Inertia с Vue/React и OpenAPI 3.1 через Dedoc Scramble.

Для подключения скопируйте `AGENTS.md` и `.agents` в корень Laravel-проекта и дополните команды проверок особенностями проекта.
